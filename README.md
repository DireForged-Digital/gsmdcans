# GSMDCA NS

<!-- One or two sentences on what the app is for and who uses it. -->

A React Native app for iOS, Android and the web, built with [Expo](https://expo.dev) and
[Firebase](https://firebase.google.com).

## Stack

- Expo SDK 57 (React Native 0.86, React 19), Expo Router, development builds
- Native UI: Expo UI (SwiftUI / Jetpack Compose), NativeTabs, SF Symbols / Material Symbols
- Firebase: React Native Firebase on iOS/Android, the Firebase JS SDK on web;
  Firestore, Auth, Cloud Functions (Node 24), Hosting
- TanStack Query over a repository layer (`src/services/repository.tsx`)
- Tests: Jest + Testing Library, Firestore rules tests, Maestro (native),
  Playwright + axe (web)

## Requirements

- macOS with Xcode (iOS) and Android Studio (Android SDK and an emulator)
- [mise](https://mise.jdx.dev), which installs the pinned Node and pnpm versions from `mise.toml`
- Java 21+ (for the Firebase emulators)
- [Maestro](https://maestro.dev) (native end-to-end tests)

## Getting started

```sh
mise install                 # Node 24 and pnpm
pnpm install                 # app and workspace packages
npm ci --prefix functions    # Cloud Functions (separate npm project)
pnpm prebuild:dev            # generate ios/ and android/ for the dev variant
pnpm ios                     # build and run the dev build on the iOS Simulator
pnpm android                 # build and run the dev build on the Android emulator
```

After the first build, `pnpm start` is enough until native dependencies change.

### Build variants

`APP_VARIANT` selects `development` (default; separate bundle ID and the dev Firebase project)
or `production`. The native `ios/` and `android/` folders are generated by `expo prebuild`
and not committed.

## Scripts

| Command                            | What it does                                               |
| ---------------------------------- | ---------------------------------------------------------- |
| `pnpm start`                       | Start Metro for the dev build                              |
| `pnpm web`                         | Run the web app                                            |
| `pnpm typecheck`                   | TypeScript for the app, Functions, rules tests and web E2E |
| `pnpm lint` / `pnpm format`        | ESLint / Prettier                                          |
| `pnpm test` / `pnpm test:coverage` | Unit and component tests                                   |
| `pnpm test:rules`                  | Firestore security rules against the emulator              |
| `pnpm test:functions`              | Cloud Functions tests against the emulators                |
| `pnpm e2e`                         | Maestro smoke flows on iOS and Android                     |
| `pnpm e2e:a11y`                    | Maestro at the largest text size and in dark mode          |
| `pnpm e2e:web`                     | Playwright and axe against the static web export           |

## Firebase

Two projects, `dev` and `prod` (aliases in `.firebaserc`). The config files in
`firebase/dev` and `firebase/prod` and the web config in `.env` are public identifiers,
not secrets; access is controlled by Firestore security rules.

Local emulators: `pnpm exec firebase emulators:start` (UI on http://localhost:4000).
